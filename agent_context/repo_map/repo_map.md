# Repository Map

**Last updated:** July 15, 2026 (evaluation MVP slice merged)

## Root Files
- `README.md`: project statement, implemented architecture, and end-to-end run instructions.
- `LICENSE`: placeholder text (`TBD`) at the moment.

- `docker-compose.yml`: empty `services` object (unused).

## Source Tree (`src/`)
- `main.py`: base ETL (pipeline version `1.1.0`). Reads ARC-AGI JSON tasks, validates grids, transforms to long-format rows, enforces the frozen tasks schema, writes Hive-partitioned Parquet. **Unchanged by the inference slice.**
- `contracts.py`: inference/analytics data contracts — `ETL_REQUIRED_COLUMNS`, frozen `INFERENCE_PARQUET_SCHEMA` (28 columns), `ANALYTICS_METRIC_COLUMNS`, strict `validate_columns()` guard.
- `prompt_builder.py`: reconstructs tasks from the tasks Parquet and renders the versioned prompt (`arc_grid_v1`).
- `providers.py`: `BaseProvider` + `MockProvider` (deterministic, offline) + `OpenAIProvider` / `OllamaProvider` (stdlib urllib, graceful config failures).
- `grid_parser.py`: extracts and validates JSON grids from model text (fenced blocks, prose, malformed input).
- `evaluator.py`: exact match, same shape, cell accuracy, differing cells.
- `failure_taxonomy.py`: deterministic failure-mode classification v1.
- `run_inference.py`: batch inference CLI (incremental Parquet flushes, per-task error tolerance, `_manifest.json` per run).
- `build_analytics.py`: rebuilds analytics tables (+ build manifest) and generates `reports/mvp_report.md`.
- `manifest.py`: `_manifest.json` writers — git SHA, timestamps, schema versions, portable paths.
- `DECISIONS.md`: technical decision log — Decisions 1–7 (ETL), 8–13 (providers, mock reproducibility, inference schema, taxonomy, scoring, hardening).

## Scripts
- `scripts/fetch_arc_data.py`: populates `data/raw/evaluation/` — downloads ARC-AGI-1 from GitHub (`--limit N`, `--dataset`) or copies bundled offline fixtures (`--sample`).
- `scripts/smoke_test.py`: end-to-end ETL→mock→analytics smoke test in an isolated temp dir (offline, ~2–10 s, `SMOKE PASS`/non-zero exit).

## Tests
- `tests/test_grid_parser.py`, `tests/test_evaluator.py`, `tests/test_failure_taxonomy.py`: stdlib `unittest` suite (34 tests) — run with `python -m unittest discover -s tests`.
- `tests/fixtures/sample_tasks/*.json`: six small synthetic ARC-style tasks (identity, flip, color swap, rotation, tiling, fill) used by the offline `--sample` mode and the smoke test.

## Notebooks
- `notebooks/inference_input_reader.py`: reference snippet for loading the partitioned Parquet dataset; superseded operationally by `src/prompt_builder.py` but kept as documentation.

## Docs & Reports
- `docs/MVP_REMAINING_PLAN.md`: implementation plan for the evaluation MVP slice.
- `docs/REVIEW_CHECKLIST.md`: reviewer commands, expected runtimes/outputs, failure points, acceptance criteria.
- `reports/mvp_report.md`: generated evaluation report (regenerated by `build_analytics.py`).

## Data Layout (gitignored, created at runtime)
- `data/raw/evaluation/`: ARC-AGI task JSON files (one file per task).
- `data/parquet/evaluation/`: Hive-partitioned normalized tasks (`split=<train|test>/task_id=<id>/`).
- `data/parquet/evaluation_errors/`: Hive-partitioned ETL validation errors (written only when errors exist).
- `data/parquet/inference/runs/<run_id>/`: one directory per inference run (`part-NNNN.parquet` + `_manifest.json`); plain (non-Hive) names so `run_id` stays a physical column (see DECISIONS Decision 10).
- `data/parquet/analytics/`: derived layer, fully rebuilt by `build_analytics.py` — `_manifest.json` + `fact_inference_results/` (Hive: `provider`/`model_name`), `summary_by_model/`, `summary_by_failure_mode/`, `summary_by_task/`.
- `logs/quality_<timestamp>.log`: per-run text log of ETL grid validation failures.

## Current Architectural Reality
What exists:
- Batch folder ingestion with per-file error tolerance (ETL, frozen schema).
- Data bootstrap for both online (GitHub download) and offline (bundled samples) usage.
- Provider abstraction with a deterministic mock and optional OpenAI/Ollama backends.
- Versioned prompt building from the tasks Parquet.
- Response parsing/validation, cell-level scoring, and failure taxonomy v1.
- Inference results in a frozen, validated 28-column Parquet schema with full lineage (`task_id`, `source_task_partition`, `prompt_version`, `run_id`).
- Analytics tables plus a regenerable markdown report.

What does not exist yet:
- Package layout with `__init__.py` files (scripts import as siblings within `src/`).
- CI configuration (tests + smoke exist but run manually).
- Model/provider configuration files (`configs/` unused; env vars only).
- Versioned prompt registry beyond the `PROMPT_VERSION` constant.
- `transformation_type` labeling of tasks (column exists, still NULL).
- Orchestration (Airflow/n8n) and Docker services.

## Minimal Data Flow
1. `scripts/fetch_arc_data.py` populates `data/raw/evaluation/`.
2. `src/main.py` validates and normalizes to `data/parquet/evaluation/`.
3. `src/run_inference.py` builds prompts, calls a provider, parses, scores, labels failure modes, writes `data/parquet/inference/runs/<run_id>/`.
4. `src/build_analytics.py` rebuilds `data/parquet/analytics/` and `reports/mvp_report.md`.

## How to Run
From the repository root (offline path shown; see README for real providers):

```bash
python scripts/fetch_arc_data.py --sample
python src/main.py
python src/run_inference.py --provider mock --model baseline
python src/build_analytics.py
```

Or `make mvp-offline`. Verify with `python -m unittest discover -s tests`
and `python scripts/smoke_test.py` (see `docs/REVIEW_CHECKLIST.md`).

## Gaps to Track
- No package initializers (`__init__.py`) or installable module layout.
- No CI wiring for `make test` / `make smoke` (manual for now).
- No centralized model/provider config files (env vars only).
- Failure taxonomy is v1 (heuristic); finer categories are future work.
- `--split` in inference supports only `test` (by design for the MVP).
