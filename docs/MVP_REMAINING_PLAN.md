## 3. Execution Order

1. **Data bootstrap** — `scripts/fetch_arc_data.py` downloads the public
   ARC-AGI-1 evaluation set (fchollet/ARC-AGI) into `data/raw/evaluation/`
   with `--limit N`; `--sample` copies bundled offline fixtures from
   `tests/fixtures/sample_tasks/` so the whole pipeline runs with no network.
2. **Run existing ETL** (`python src/main.py`) — unchanged — to produce
   `data/parquet/evaluation/`.
3. **Contracts** — `src/contracts.py` declares the columns the inference
   stage requires from the ETL, the frozen inference-results schema, and the
   analytics schemas, plus a generic column/nullability guard (same behavior
   as `validate_output_schema` in `main.py`, kept separate so the ETL stays
   untouched).
4. **Grid parser** — robust extraction of the first JSON 2D int array from
   model text (plain, fenced, or with surrounding prose) + ARC validation
   (rectangular, ints 0–9).
5. **Prompt builder** — versioned `arc_grid_v1` prompt from task train
   examples + one test input; includes parquet→task reconstruction helpers
   (adapted from `notebooks/inference_input_reader.py`).
6. **Providers** — `BaseProvider`, `MockProvider` (deterministic, offline,
   exercises every failure mode), `OpenAIProvider` and `OllamaProvider` via
   stdlib HTTP (no new dependencies); real providers fail gracefully with
   clear messages when credentials/servers are absent.
7. **Evaluator** — exact match, same shape, cell accuracy, differing cells;
   safe on parse failures.
8. **Failure taxonomy v1** — deterministic mapping to
   `exact_match | parse_error | api_error | empty_response | shape_error |
   symbol_error | spatial_error | unknown_error` (color-histogram heuristic
   splits symbol vs spatial).
9. **Runner** — `src/run_inference.py` CLI; reads ETL parquet, one row per
   (task, test example); incremental parquet flushes so partial progress is
   never lost; writes to `data/parquet/inference/runs/<run_id>/`
   (plain directory names, NOT Hive-style, so `run_id` stays a physical
   column in every part file and pyarrow merges the whole tree conflict-free).
10. **Analytics** — `src/build_analytics.py` reads all runs, writes
    `data/parquet/analytics/{fact_inference_results,summary_by_model,summary_by_failure_mode,summary_by_task}/`
    and generates `reports/mvp_report.md`.
11. **Docs** — README end-to-end commands, DECISIONS 8–12, `.env.example`
    provider variables, agent_context sync, Makefile targets.
12. **Verification** — clean `data/`, re-run the full chain with the mock
    provider, confirm outputs and report.

## 4. Assumptions

- **A1.** The ETL and its frozen schema are the source of truth and must not
  change; new layers only *read* `data/parquet/evaluation/`.
- **A2.** The public ARC-AGI-1 evaluation set includes ground-truth test
  outputs, so scoring is always possible on this dataset. If an output is
  absent (hidden-set style), rows are still produced with evaluation fields
  NULL and `failure_mode` left NULL (not evaluable).
- **A3.** One inference row per (task_id, test example). Most evaluation
  tasks have exactly 1 test example; some have 2 — hence an explicit
  `test_example_id` column.
- **A4.** The mock provider must exercise the full metric surface
  deterministically (correct answers, near misses, shape errors, malformed
  and empty responses) so the pipeline is demonstrable without credentials.
  It is a pipeline-testing tool, not a scientific baseline.
- **A5.** Real providers use stdlib `urllib` (no new dependencies).
  `OPENAI_API_KEY` / `OLLAMA_HOST` come from environment variables; cost is
  estimated from returned token usage where available, else 0.0.
- **A6.** Analytics uses pandas + pyarrow only; `duckdb` (in
  `requirements.txt`) stays optional for ad-hoc exploration.
- **A7.** Everything runs from the repository root with
  `python src/<script>.py` (scripts resolve paths relative to their own
  location, so cwd does not matter).

## 5. Out of Scope

- Solving ARC / prompt optimization for leaderboards.
- Orchestration frameworks (Airflow/n8n), Docker services, retries beyond a
  simple per-call policy.
- Refactoring `src/main.py` into a package (Priority 2 in
  `agent_context/tasks/current_priorities.md` — deferred).
