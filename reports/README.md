## Regenerate a report

```bash
python src/build_analytics.py --experiment-id <label>
# or point at one run:
python src/build_analytics.py \
  --runs-path data/parquet/inference/runs/<run_id> \
  --report-path reports/my_report.md \
  --experiment-id <label>
```

## Metric glossary (reports)

| Column | Meaning |
| --- | --- |
| `exact_match_rate` | Attempt-level accuracy |
| `solved_rate` | Item-level pass@k (any attempt exact) |
| `task_solved_rate` | ARC-official (all test examples on task correct) |
| `parse_error_rate` | Share of rows where grid parse failed |
| `avg_cell_accuracy` | Secondary diagnostic — not a leaderboard metric |

See Decision 21 in `src/DECISIONS.md`.
